# SIM – Security Incident Mapping

SEN202 Weekend 1 project. SIM is a proposed web platform through which students, staff and landlords can report security incidents on campus and track their reports.

## Run locally

Open `index.html` in a modern browser. No installation is required. Submitted reports are saved only in that browser's local storage and are not sent to any server or to campus staff.

## Project contents

- `index.html`: the website (form, tracking, statistics and emergency contacts), with its styles and script in the same file
- `docs/SRS.docx`: Software Requirements Specification
- `docs/questionnaire.md`: questionnaire design for Google Forms
- `docs/object-listing.md`: objects in the system
- `docs/ishikawa.drawio`: Ishikawa (fishbone) problem analysis, opens in draw.io
- `docs/use-case.svg`: use case diagram
- `docs/SIM_Print_Pack.pdf`: printable submission pack (cover, SRS, use case diagram, Ishikawa diagram, object listing, code listing)

## Important limitation

SIM is an educational prototype. It does not transmit reports, verify reports, protect identity through a backend, or notify responders. It is not monitored for emergencies. In an emergency, contact campus security or local emergency services directly.
